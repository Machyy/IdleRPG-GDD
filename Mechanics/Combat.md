Souboj je turn-based, hráč má na výběr v základu Basic Attack a Basic Defend, po dosažení levelu 5 se hráči odemknou frakce a vybere si jednu z nich. Frakce dají hráč speciální Damage a Defend abilitu a Basic Defend je zruší, ale Basic Attack zůstává.
# Chaos meter
Every battle has a Chaos Meter that is shared between the player and their opponent.  
Once the meter is filled, a random event is triggered.
## Chaos fills
- +10 every turn.
- +15 when someone misses.
- +20 when someone crits.
- +25 when a faction ability fails.
- +30 when player or boss drops below 25% HP.
- Bosses can have custom meter triggers.
## Chaos events
| Event                           | Effect                                                                                                                           |
| ------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| **New Patch Notes Dropped**     | “Basic Attack was underperforming.” Player gets +25% damage for 2 turns. Then enemy gets angry because they “read the comments.” |
| **Emergency Nerf**              | Strongest active buff on either side is removed. Text: “The devs saw fun happening.”                                             |
| **Rollback the Rollback**       | Undo last turn’s damage, then apply 50% of it again to a random target. Nobody understands why.                                  |
| **Hotfix 0.0.0.1b**             | Heals both sides for a small amount, but also applies Burn because the fix is overheating.                                       |
| **Memory Leak**                 | Every turn damage increases by 5%, but both sides lose 2% max HP.                                                                |
| **Lag Spike**                   | Next attack happens one turn late, then hits twice because packets arrived together.                                             |
| **Terms of Service Updated**    | Player must “accept” by losing 1 turn OR gains a random buff if Intelligence is high enough.                                     |
| **Balance Team Panic**          | The losing side gets +20% defense. The winning side gets a sarcastic achievement.                                                |
| **Asset Not Found**             | Enemy weapon disappears for 1 turn. If player is unlucky, player pants disappear instead: -10% defense, +10% dodge from shame.   |
| **Paywall Misfire**             | A fake popup appears. Closing it gives scrap. Clicking it does nothing except say “nice try.”                                    |
| **Critical Bug Became Feature** | Last negative effect becomes a positive one, or vice versa. Poison becomes “Spicy Regen.” Shield becomes “Heavy Anxiety.”        |
